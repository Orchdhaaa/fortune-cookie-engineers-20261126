One fortune cookie message for a software engineer, 120 characters or fewer: "Your pull request will be approved in seconds. The merge conflict will outlive you." Good news first, then the twist: the approval is instant, but the merge conflict is forever.

## Run it

```sh
node main.ts
```

`main.ts` writes the fortune to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when the harness sets it), verifying first that it is a single line of 1-120 characters with no dash and no control characters.
